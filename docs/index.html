What it handles

Five jobs that otherwise eat a morning each month, in one window.

Format

Sweeps five encodings against four delimiters until the file parses, finds the real header row wherever it is hiding, recognises the export's shape, and hides the columns nobody reads.

Compare

Diffs this month's scan against last month's on asset plus vulnerability title, so remediation evidence and new findings separate themselves.

Wiz

Flattens a nested issuesV2 GraphQL response down to one row per security-tool finding, surviving the nulls the API returns in place of missing objects.

Group by business unit

Looks every hostname up in a local inventory database and splits the findings into one sheet per team. Whatever fails to match lands in _Unmapped, which doubles as a coverage report.

Qualys

Lists, filters and downloads reports over the API, then formats them in the same pass. Handles first-login EULA activation for API-only accounts.

Running it

Python 3.8 or newer. Four tabs work immediately; the Qualys tab needs an account first.

# install
pip install PyQt5 pandas openpyxl xlrd
python VM_File_Formatter.py
# only if you want the Qualys tab
export QUALYS_API_URL="https://qualysapi.qualys.com"   # your pod
export QUALYS_API_USER="<api username>"
export VAULT_SECRET="<a long random passphrase>"
python VM_File_Formatter.py --encrypt-qualys-password

No credentials ship with this repository. The pod URL, username, vault secret and password token are all blank by default. The password is stored only as a token encrypted against a secret held outside the source, and is decrypted in memory for the moment a request is signed. Until all four are set, the Qualys tab names exactly what is missing and does nothing.
